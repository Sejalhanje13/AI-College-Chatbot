## 🎯 How to Use Advanced Features

### Dark Mode 🌙
1. Click moon icon in header
2. Theme switches instantly
3. Preference saved automatically
4. Works across all pages

### Voice Input 🎤
1. Click microphone icon
2. Speak your question clearly
3. Text appears automatically
4. Click again to stop
**Note**: Requires Chrome or Edge browser

### Export Chat 💾
1. Click download icon
2. Chat history downloads as .txt
3. Includes all messages with timestamps
4. Open with any text editor

### Search History 🔍
1. Click search icon in input area
2. Type search query (min 2 chars)
3. View matching messages
4. Click outside to close

### Clear Chat 🗑️
1. Click trash icon
2. Confirm deletion
3. Page reloads fresh
4. History permanently deleted
